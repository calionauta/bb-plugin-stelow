# Interface Contrast and Scope Map

User documentation (canonical):
https://calionauta.github.io/stelow/docs/plugin/scope-contracts/

Operator summary: the `scope` stage owns the approved delivery map;
scope-mapping is a method, not a stage. Contrast receipts separate
agent evidence from human authority; challenges name scopes, reason,
evidence, and destination; native `needs_input` answers resume a run only
when boundary and versions match.
