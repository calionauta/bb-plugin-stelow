# Team playbook (experimental)

User documentation (canonical):
https://calionauta.github.io/stelow/docs/plugin/team-playbook/

Operator summary: one bb per teammate, GitHub as the team room. Owner
labels (risk tier, specialty, assignee); operator runs the card in their
own bb; specialist verdicts at marked gates (consult 🟡 or approve 🔴)
arrive as issue comments and are filed via gate approval.
